This project implements a scroll-based animation where boxes dynamically scale and change appearance as they approach the center of the viewport during scrolling. The animation enhances visual engagement and user experience, making it perfect for interactive web designs.

Installation
1. Clone the repository:
git clone https://github.com/your-username/scroll-animation.git
cd scroll-animation

2. Open the xampp and place project into htdocs folder
3. run apache server
4. run MySQL
5. goto browser and type localhost/ScrollAnimation
